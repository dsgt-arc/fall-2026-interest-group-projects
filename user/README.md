# Student submissions

Add your homework under your own GitHub handle:

```text
user/
  <your-github-handle>/
    homework-1/
      README.md
      ...your code or notebooks...
```

For Homework 1, include a short README describing your changes, results, how you evaluated your RAG improvements, and how to run your work.

For Homework 2 Part 2 (vision retrieval), put your answers to the discussion questions in `user/<your-github-handle>/homework-2/README.md`, and add the `summary.csv` from your run.

Keep your work in your own folder, leaving the shared starter code under `homework-1/` intact. Open a pull request to this repository when your submission is ready for review.

Commit code, notebooks, and small results files only. Do not commit downloaded paper collections, model weights, credentials, or local environments.
